# Vision

This area will own camera input, object detection, and target coordinates. It should expose a clear output for the PC communication module without depending on Arduino details.

## Planned Inputs and Outputs

- Input: webcam or compatible USB camera frames.
- Output: the agreed target data defined in [the integration interface](../../docs/interface.md).

Add the implementation, Python dependencies, model source, and run instructions here when they are selected. Experimental code can stay in [prototypes](../../prototypes/README.md) until the team adopts it.
